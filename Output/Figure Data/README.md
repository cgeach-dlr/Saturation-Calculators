The files here contain the data plotted in the figures of "Saturation Effects in Resonance Lidar Measurements" and "Saturation Effects in Potassium Resonance Lidar Measurements: Modeling, Temperature Effects, and Empirical Validation" (DOIs to be added when available). The plots can be re-generated using the scripts indicated below.

"Saturation Effects in Resonance Lidar Measurements":
- The data for Figure 1 are contained in the files 'Simple_Delta_nu_L.txt' and 'Simple_nu_L.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_simple_data.py'.
- The data for Figure 2 are contained in the files 'Na_saturation.txt' and 'Na_biases.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_sodium_data.py'.
- The data for Figure 3 are contained in the files 'Fe_saturation.txt' and 'Fe_biases.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_iron_data.py'.
- The data for Figure 4 are contained in the files 'He_saturation.txt' and 'He_biases.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_helium_data.py'.
- The data for Supplementary Figure 1 are contained in the files 'Na_saturation_SI.txt' and 'Na_biases_SI.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_sodium_data_SI.py'.
- The data for Supplementary Figure 2 are contained in the files 'He_saturation_SI.txt' and 'He_biases_SI.txt'. The figure can be reproduced using the script 'Sodium iron and helium / plot_helium_data_SI.py'.

"Saturation Effects in Potassium Resonance Lidar Measurements: Modeling, Temperature Effects, and Empirical Validation":
- The data for Figure 1 are contained in the files 'K_effective_spectrum.txt' and 'K_intrinsic_spectrum.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_model_data.py'.
- The data for Figure 2 are contained in the files 'K_saturation_nuL.txt' and 'K_saturation_E.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_model_data.py'.
- The data for Figure 3 are contained in the files 'K_profile.txt' and 'K_shots.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_observation_data.py'.
- The data for Figure 4 are contained in the file 'K_measurements.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_observation_data.py'.
- The data for Figure 5 are contained in the files 'K_comparison_a.txt' through 'K_comparison_f.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_observation_data.py'.
- The data for Figure 6 are contained in the files 'K_T_biases_150.txt', 'K_T_biases_200.txt', 'K_w_biases_150.txt' and 'K_w_biases_200.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_model_data.py'.
- The data for Figure 7 are contained in the files 'K_comparison2_a.txt' through 'K_comparison2_d.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_observation_data.py'.
- The data for Supplementary Figure 1 are contained in the files 'K_saturation_nuL_SI.txt' and 'K_saturation_E_SI.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_model_data_SI.py'.
- The data for Supplementary Figure 2 are contained in the files 'K_T_biases_150_SI.txt', 'K_T_biases_200_SI.txt', 'K_w_biases_150_SI.txt' and 'K_w_biases_200_SI.txt'. The figure can be reproduced using the script 'Potassium / plot_potassium_model_data_SI.py'.

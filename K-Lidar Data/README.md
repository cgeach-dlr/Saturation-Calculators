  This directory includes the data analyzed from the potassium lidar operated by IAP in Kühlungsborn, Germany. Note that the files must be unzipped into NetCDF files in order to be read by the python scripts.

  'IAP-Potassium-2010.zip' contains data for 25-26 January 2010 and the evening of 26 January 2010.
  'IAP-Potassium-2011a.zip' contains data for 27-28 January 2011 and the evening of 28-29 January 2011.
  'IAP-Potassium-2011b.zip' contains data for 24-25 February 2011.
